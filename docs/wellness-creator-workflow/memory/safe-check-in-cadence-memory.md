# Safe Memory — Check-in Cadence

*An example of safe cadence metadata Matterhorn Memory may remember. Candidates only — nothing is written automatically.*

> This content is for general fitness and wellness education only. It is not medical advice, diagnosis, or treatment.

## Safe to remember (cadence)

- **Check-in cadence:** weekly, on Mondays.
- **Format:** the standard weekly check-in form (sessions, adherence, energy, wins/blockers — all self-reported).
- **Renewal / follow-up preference:** send a renewal note at the end of each block.
- **Communication preference:** short message, no long emails; the creator sends it themselves (email is a planned, not-live hook).

## Never stored

No diagnosis, medication advice, treatment plans, guaranteed outcomes, eating-disorder care, pregnancy or post-surgery medical plans, or private health records. No wallet secrets or credentials of any kind.
