V2 Visual Redesign
7 Problems V2 Solves
These are the specific visual quality problems Codex must fix in the implementation.
P1
Too Many Outlined Boxes
Every card has border: 1px solid var(--border) — they stack as outlines competing for attention. V2: surface fills + subtle 1px separators.
P2
Monotonous Dark UI
Flat #0C0C0C everywhere with no warmth. V2: #111111 surface cards, per-desk accent tints, richer hierarchy.
P3
Profile/Wallet Hidden
Wallet address absent on desktop. V2: right rail profile card with truncated address + copy button.
P4
Side Rail = Info Dump
Every status, chip, and count crammed into the nav rail. V2: nav rail = clean icon+label; content in main + right rail.
P5
Fake Protocol Icons
Emoji (⚡💎📊) instead of SVG icons. V2: full SVG icon set per desk, currentColor, 24×24px, 1.5px stroke.
P6
Ugly Curved Session Cards
Heavy border-radius: 12px + nested card grids. V2: border-radius: 4px, no nested cards, metric chips not sub-cards.
P7
Bittensor Too Expert-Oriented
Raw Subtensor data, validator addresses, subnet IDs — developer dashboard. V2: beginner view by default, Expert toggle.
V2 Goal
Every problem above has a corresponding visual example on the next screens. Codex must verify each fix against the annotated examples before calling a desk done.
