# Retro workspace surface

Mode: Operate. Scope: product-wide shared system, shell and core workflow;
secondary Read pages inherit this system but preserve their prose hierarchy.

## Direction contract

THESIS: a clear retro workbench for choosing a model, opening a desk and doing
real work. Refuse both the soft dashboard template and a simulated trading game.

OWN-WORLD: flat light paper/charcoal planes, ink outlines, violet actions, ice
selection, 2–4px corners and hard offset shadows. Keep the real logo, protocol
marks and readable incumbent sans; no new raster decoration or pixel body text.

STORY: choose a model, see all five desks, open a composer in one action. Real
readiness and review states stay visible; a visual style is not execution proof.

FIRST VIEWPORT: anchored left navigation, compact title/model/tools header, five
desk choices in an open work area; chat occupies the center once selected.
Primary action sits with the composer. Mobile navigation is an explicit drawer.
Signature interaction: an enabled action compresses its hard shadow on press;
focus is an independent high-contrast outline, motion-reduce removes movement.

FORM: candidate 4, retro application workbench; concept seed e987a9c1. Grounded
list: reference component catalog, early desktop utility, printed field guide,
retro application workbench, index-card organizer, protocol explorer table,
single-document notebook. User-pinned neobrutalism wins over catalog alternatives.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## Challenger judgments

All declined as replacements: rhythm machine (time-grid does not fit desks;
keep decisive active-state contrast), arcade CRT (pixel text hurts long reading;
keep strict small palette), cloud quarry (spatial manipulation unrelated to tasks;
keep clear section planes), stage cyclorama (atmospheric cues obscure approvals;
keep labelled states), viewfinder (full-bleed HUD crowds chat; keep center focused
on the task), industrial plate (overlapping planes obscure accessible controls;
keep consistent hard-shadow geometry). These raises strengthen the requested
retro system without importing motifs. No alternate selected or comps approved.

## Constraints

One default-off release flag; same data/routes/drafts. No backend permission,
agent, wallet, accounting, STM or production changes. Both themes; 390/768/1440
and actual preview width. Build directly in React under user's sleep-work request;
optional questions do not block the explicit start instruction.
