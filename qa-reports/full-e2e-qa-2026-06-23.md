### QA-2026-06-23-003 - Engine-backed smoke tests failed when local engine binary was absent

- Severity: P1 local QA blocker
- Area: app smoke harness
- Repro: `pnpm test:health`, `pnpm test:e2e`, and other engine-backed smoke scripts on a machine without `opencode` or a configured Matterhorn Work engine binary.
- Actual: app harness failed with `spawn opencode ENOENT`.
- Fix: app smoke utilities now:
  - use `matterhorn-work-test` as the test client label;
  - fail clearly when `MATTERHORN_WORK_ENGINE_BIN` or `OPENCODE_BIN` is explicitly configured but missing;
  - skip cleanly with an actionable message when no engine binary is configured and no default `opencode` binary is present.
- Fix PR: [#517](https://github.com/matterhornso/matterhorn-work/pull/517)
- Retest: `pnpm test:health` and `pnpm test:e2e` passed by cleanly skipping engine-backed checks in this environment.
